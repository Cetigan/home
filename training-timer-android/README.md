# Таймер Ната (Android)

Приложение-таймер для интервальных тренировок. Написано заново на Kotlin,
чтобы **не зависать и не останавливаться, когда приходит звонок или когда
приложение свёрнуто / экран выключен**.

Звуковые сигналы:

- **Свисток** — в конце каждого подхода.
- **Сигнал-предупреждение** (три коротких бипа) — за 5 минут до конца тренировки.
- **Гудок поезда** — в конце всей тренировки (+ вибрация).

## Что решает главную проблему

Старое приложение переставало работать в фоне и во время звонков. Здесь таймер
работает внутри **foreground-сервиса** (`TimerService`) с постоянным
уведомлением, поэтому система его не «усыпляет»:

- **Foreground Service + постоянное уведомление** — процесс не убивается при
  сворачивании и во время звонка.
- **PARTIAL_WAKE_LOCK** — CPU продолжает считать время при выключенном экране.
- **Отсчёт по `SystemClock.elapsedRealtime()`** (по абсолютным меткам времени, а
  не «тиками») — таймер не «плывёт», даже если систему что-то притормозило.
- **Свисток через `SoundPool` с `USAGE_ALARM`** — звук проходит даже в
  беззвучном режиме и после завершения звонка.

## Как работает таймер

Интервальная тренировка повторяет циклы **Работа → Отдых** до тех пор, пока не
истечёт общее время тренировки. В конце каждого подхода звучит **свисток**.
Каждые 4 подхода короткий отдых заменяется на длинный «перерыв между
упражнениями» (если галочка включена). За 5 минут до конца всей тренировки
звучит **сигнал-предупреждение**, а по завершении — **гудок поезда** и вибрация.

Ползунки на главном экране:

| Ползунок | Значение по умолчанию | Что задаёт |
|---|---|---|
| Установите время тренировки | 40 мин | общая длительность сессии |
| Длительность подхода (работа) | 45 сек | время одного подхода |
| Перерыв между подходами | 75 сек | короткий отдых |
| Перерыв между упражнениями | 2 мин | длинный перерыв (по галочке) |

> Ползунок «Длительность подхода» добавлен по сравнению со скриншотами: без
> него автоматический интервальный таймер не может сам чередовать работу и
> отдых. Если нужна другая логика — скажите, поправлю.

## Сборка

1. Открыть папку `training-timer-android/` в Android Studio (Giraffe и новее).
2. Дать студии скачать Android SDK (compileSdk 34) при первом запуске.
3. Нажать **Run** — или из терминала:

```bash
cd training-timer-android
./gradlew assembleDebug
# готовый APK: app/build/outputs/apk/debug/app-debug.apk
```

Минимальная версия Android: 8.0 (API 26). Целевая: Android 14 (API 34).

## Разрешения

- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` — работа в фоне.
- `WAKE_LOCK` — точный отсчёт при выключенном экране.
- `POST_NOTIFICATIONS` — уведомление с таймером (Android 13+).
- `VIBRATE` — вибрация в конце.
